### 遇到的问题
反转链表有两种思路 一种是迭代  一种是递归  

迭代：
迭代主要是 如果链表是空的或者就只有一个元素 就结束了
            如果链表不是那样  先搞一个头节点 需要两个指针 一个指针指向要走的节点a  一个指向a的下一个 然后依次把a插入到头节点之后 直到结束

递归：
递归很巧妙  利用函数 先找到最后一个节点 将这个节点作为新的头节点  然后回溯过程中改变指针指向 代码：
ListNode* reverseList(ListNode* head) {
    if (head==nullptr||head->next == nullptr)
        return head;
 ListNode *new_head = reverseList(head->next);
 head->next->next = head;
 head->next = nullptr;
 return new_head;
}
head->next->next = head; 这句更巧妙  head本身代表当前节点  而它的next正是回溯的上一个节点  我需要把回溯的上一个节点指向head 于是就有了这句
