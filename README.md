# Frontend Learning Plan

## 学习目标

本仓库用于记录 2026 年 5 月前端学习过程，主要目标是：

1. 掌握 HTML / CSS 基础；
2. 熟悉 Flex 和 Grid 布局；
3. 能够完成响应式个人主页；
4. 掌握 JavaScript 基础语法和 DOM 操作；
5. 完成一个 JavaScript 小项目；
6. 养成 GitHub 提交、学习记录和 AI 辅助学习习惯。

## 5 月学习安排

### 第 0 周：启动准备

- 配置开发环境；
- 创建 GitHub 仓库；
- 建立学习目录；
- 建立 README；
- 建立 AI 辅助学习记录模板。

### 第 1 周：HTML / CSS 基础 + Flex 布局

目标：完成个人主页的基础结构和样式。

### 第 2 周：Grid 布局 + 响应式页面完善

目标：完善个人主页，实现 PC、平板、手机端适配。

### 第 3 周：JavaScript 基础 + DOM 操作

目标：给个人主页增加一个交互功能，例如深色 / 浅色模式切换。

### 第 4 周：JavaScript 小项目

目标：完成安全设备基线检查筛选系统。

## AI 使用方式

根据任务规模选择不同 AI 工具：

- 大项目：优先使用 Claude Code 或 Codex，辅助理解项目结构、分析代码、重构功能；
- 小问题：使用 ChatGPT 网页版进行提问，例如语法解释、报错分析、代码审查；
- 原则：不直接复制 AI 生成的完整代码，重点让 AI 帮助解释思路、检查错误、优化结构。

## 本月最终交付物

1. 响应式个人主页；
2. 安全设备基线检查筛选系统；
3. 至少 3 次 AI 代码审查记录；
4. 数组题练习记录；
5. 10 个前端基础面试问答；
6. 5 月学习复盘。
